# keepquery

Keep digests and query fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/keepquery/

## Install / run

```bash
git clone https://github.com/theworker02/keepquery.git
cd keepquery
node src/cli.js
node --test
```
